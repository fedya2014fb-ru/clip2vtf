# Third-party components

`clip2vtf.exe` bundles the following, each under its own license:

| Component | License |
| --- | --- |
| Python 3.14 runtime | PSF License |
| Tcl/Tk 8.6 (tkinter) | Tcl/Tk License (BSD-style) |
| [Pillow](https://github.com/python-pillow/Pillow) | MIT-CMU (HPND) |
| [NumPy](https://numpy.org) (with OpenBLAS) | BSD-3-Clause |
| [srctools](https://github.com/TeamSpen210/srctools) (with libsquish) | MIT |
| [tkinterdnd2](https://github.com/Eliav2/tkinterdnd2) / tkdnd | MIT / BSD-style |
| OpenSSL (Python `ssl`, for downloading images) | Apache-2.0 |

Not bundled: Valve's `vtf2tga.exe`. It is used from the local Team Fortress 2 installation.
